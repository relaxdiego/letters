# Letters to My Sons

These are the letters Mark Maglana wrote to his sons. You can read them at
<https://letters.maglana.com>.

This repository holds the same letters twice, in two shapes. Either one is
enough.

**As the website.** Click the green **Code** button above, then **Download
ZIP**. Unzip it, find the file named `index.html`, and double-click it. The
site opens in your browser, from your own computer, with no internet needed
and nothing to install. The links work from letter to letter. If one ever
opens a plain list of file names, click `index.html` in that list — that is
the page.

**As plain text.** Open the folder `content/letters/`. Every file in it is one
letter. Each file name starts with the date it was written, so sorting the
files by name puts them in order. The files end in `.md`, but that is nothing
to worry about — they are plain text. Click one here, or open it in any text
editor on any computer, and you will see the letter: a title, a date, and the
words.

`PERMISSION.md` is Mark's written permission for his family to copy, print,
and reprint these letters. A print shop may ask to see it.

Everything here is written automatically each time the site is updated.
Anything changed here by hand is replaced the next time that happens, so
please do not send changes to this repository.
